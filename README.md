# `spacemit-hal`

Rust bare-metal hardware abstraction and runtime support for SpacemiT chips.

This workspace contains the following crates:

- [`spacemit-hal`](spacemit-hal): chip-level peripheral abstractions;
- [`spacemit-riscv`](spacemit-riscv): low-level access to custom RISC-V CSRs;
- [`spacemit-rt`](spacemit-rt): bare-metal runtime support.
