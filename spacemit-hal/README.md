# `spacemit-hal`

Peripheral abstractions for SpacemiT K1/M1 and K3 SoCs.

K1/M1 and K3 use different GPIO register layouts, exposed as
`gpio::k1::RegisterBlock` and `gpio::k3::RegisterBlock`, respectively.
V100 support will require a public, revisioned register description.
