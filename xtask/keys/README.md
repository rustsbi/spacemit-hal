# Public development keys

These publicly distributed K1 sample keys are not secrets and must not be used for production secure boot.

Source: [SpacemiT U-Boot, board/spacemit/k1-x/configs/key](https://github.com/spacemit-com/uboot-2022.10/tree/676971d3a61f2583dfd53d8f7dfbc9607cea74b7/board/spacemit/k1-x/configs/key).

The container carries downstream public keys as metadata, not U-Boot, kernel or rootfs payloads.
